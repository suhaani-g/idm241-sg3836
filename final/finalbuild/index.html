Rules

Product Card Block:

Hover On

  • The box slightly scales up
  • Buttons and text inside box scale up
  • Shadow behind box appears

Hover Off

  • The box slightly scales down
  • Buttons and text inside box scale down
  • Shadow behind box dissapears

Product Card Image:

Hover On

  • The image slightly scales larger
  • The image brightness increases
  • The Image fades from bottle to face over .5 seconds

Hover Off

  • The image slightly scales smaller
  • The image brightness deceases
  • The image fades from face to bottle over .5 seconds

Add to Bag Button:

Hover On

  • The button slightly moves up
  • The button's color fades to light pink
  • The button's stroke turns to dashed

Hover Off

  • The button slightly moves down
  • The button's color fades to white
  • The button's stroke turns to solid

Product Size Button 1:

Hover On

  • Two more buttons options appear on right
  • The button moves up 1px
  • Cursor changes to finger

Hover Off

  • Two button options disappear on right
  • The button moves down 1px
  • Finger changes to cursor

Product Size Button 2:

Hover On

  • Button background color changes from grey to darker grey

Hover Off

  • Button background color changes from darker grey to grey
  • Finger changes to cursor

Click On

  • Two button options disappear on right
  • Product size button 1 text changes to product size button 2 text
  • Product size button 1 changes to light pink once then back to grey
  • Finger changes to cursor

Product Size Button 3:

Hover On

  • Button background color changes from grey to darker grey

Hover Off

  • Button background color changes from darker grey to grey
  • Finger changes to cursor

Click On

  • Two button options disappear on right
  • Product size button 1 text changes to product size button 3 text
  • Product size button 1 changes to light pink once then back to grey
  • Finger changes to cursor

Favorites Button:

Hover On

  • Heart outline color changes from black to red
  • Cursor changes to finger
  • Favorites button moves up 1 px

Hover Off

  • Heart outline color changes from red to black
  • Finger changes to cursor
  • Favorite button down up 1 px

Click On (First to favorite)

  • The heart icon fills with red

Click On (Second to unfavorite)

  • The red fill is removed, returning the heart to its outline state
